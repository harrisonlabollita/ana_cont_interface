About triqs_ana_cont_interface
******************************

A TRIQS front-end for the `ana_cont <https://github.com/josefkaufmann/ana_cont>`_ analytic
continuation library.

The continuation itself is done by ana_cont (J. Kaufmann and K. Held, *ana_cont: Python
package for analytic continuation*, Comput. Phys. Commun. **282**, 108519 (2023)). This
package supplies the TRIQS containers, the physics conventions and the diagnostics.

Written and maintained by H. LaBollita.
